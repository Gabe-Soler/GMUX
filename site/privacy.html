Privacy and security

Updated 25 November 2026

No tracking.
No accounts. No data sold.

This page explains what the GMUX website and the GMUX app collect, who else sees data when you use them, and how to report a security problem.

01 · This website

The website collects nothing itself.

It has no analytics, no cookies, no forms and no tracking pixels. Nothing is stored in your browser. Two outside services are involved in showing it to you:

  • GitHub Pages hosts the site. Like any web server, it receives your IP address and browser details to deliver the page, and may keep them in logs for security. See the GitHub Privacy Statement.
  • Google Fonts serves the typefaces. Your browser requests them from Google, which receives your IP address. See the Google Fonts privacy FAQ.

Links to GitHub and other sites are covered by those sites' own policies.

02 · The GMUX app

The app runs on your Mac.

GMUX is built from source on your own machine. The install script turns off the features that would contact the upstream project's servers:

  • No crash reports or anonymous usage analytics are sent.
  • No automatic updates are checked for or downloaded.
  • Cloud machines, the cloud VPN and phone pairing are switched off.

Your files, terminal sessions and settings stay on your Mac. GMUX has no account system and no server of its own.

The programs you run inside GMUX are separate. AI coding agents, package managers, git remotes and websites in the built-in browser send data to their own services, under their own terms.

03 · Security

Report issues privately.

A terminal runs your shell, so please don't post vulnerabilities in public issues. Report them privately instead:

  • Problems specific to GMUX (the Explorer, follow-agent mode, the commit graph or the install script): use Report a vulnerability on the GitHub repository.
  • Problems in the upstream terminal code: follow the upstream project's security policy, so the fix reaches everyone.

Include what an attacker could do, how to reproduce it, and your GMUX commit. Please don't send live tokens, keys or personal data.

GMUX is open source under GPL-3.0-or-later, so you can read every line before you build it. Builds are signed on your Mac and not notarized by Apple, which is why macOS asks you to confirm the first launch.
